Set API

MODERATOR — THAT IS YOU

You moderate by typing in the box below whenever the dialogue pauses. Your assistant is a model that works for you, not a participant: no knowledge base, never takes a turn, not one of the scientists. Its only job is to rewrite a running summary after every round, which is appended to every scientist's next prompt immediately before "it is your turn" — the position a model weighs most heavily, and what stops a long discussion dissolving into parallel monologues.

It is slot 0 in Set API. Leave that slot blank and it borrows slot 1; a small, fast, cheap model of its own is usually the better call, since it runs once per round. To read or edit the summary it keeps, use Assistant & summary at the bottom of the window.
