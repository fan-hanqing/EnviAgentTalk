Reading material

Papers, replication code, derivations — what the agent should read to understand the method. Attach as many as you need, in one pick or several; they accumulate. These go into the conversation, not onto disk.

Runtime data

Files the script opens while it runs — a coefficient table, a trained model. Put them in the tools/ folder yourself; the script runs with that folder as its working directory, so a relative path just works.
