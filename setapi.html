Set API

one file, one slot per seat · api.json ← the roundtable
The index is the identity. Slot 0 is the moderator's assistant; slot 1 is whoever sits in the first seat, slot 2 the second, and so on. The binding is by position, not by name — remove a seat at the roundtable and everyone below it moves up a slot, and starts using a different key. Each seat's card shows which slot it is using, so you can see it happen.

Slot 0 may be left blank: the moderator's assistant then borrows slot 1. Giving it a small, fast model of its own is usually cheaper, since it writes a summary after every round.

This file holds your keys in plain text. That is fine for a local tool — the server only listens on 127.0.0.1 and never serves the file as a static asset — but it is in .gitignore for a reason. Do not commit it, and do not put it anywhere a backup will sweep it up.
